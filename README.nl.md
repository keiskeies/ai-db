AiDB Studio maakt de agent het primaire startpunt: verbindingen, schema, SQL, data, dashboards, rapporten en audit delen één uitvoerbare context. Het bevat 41 database-engines, 14 productiviteitsmodules en 53 agent-tools; elke actie van de agent is zichtbaar, bestuurbaar en controleerbaar.

## Installatiepakketten

| Systeem | Architectuur | Bestanden |
|---|---|---|
| Windows | x64 | `AiDB-Studio-<version>-x64-setup.exe` (NSIS) |
| Windows | arm64 | `AiDB-Studio-<version>-arm64-setup.exe` (NSIS) |
| macOS | Apple Silicon | `AiDB-Studio-<version>-arm64.dmg` |
| macOS | Intel | `AiDB-Studio-<version>-x64.dmg` |
| Linux | x64 | `AiDB-Studio-<version>-x86_64.AppImage` / `-amd64.deb` / `-x86_64.rpm` |
| Linux | arm64 | `AiDB-Studio-<version>-arm64.AppImage` / `-arm64.deb` / `-aarch64.rpm` |

Op Windows on ARM werkt de x64-installer via systeememulatie. Op Linux installeren deb / rpm via de pakketbeheerder; de AppImage vereist FUSE 2 (of `--appimage-extract-and-run`).
