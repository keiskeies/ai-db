# 移动端与桌面端一致性排查（2026-11-03）

> 范围：移动端 App（Expo Web 构建，390×844 / 兼容 320–768）与桌面端 Agent / 数据 / 设置能力对照。
> 方法：代码对照 + Playwright 驱动真实 Bridge（`127.0.0.1:8787`）逐项操作；脚本：`scripts/qa/mobile-parity.mjs`。
> 结论：累计修复 38 项（3 个用户反馈 + 同源与能力补齐）；剩余差异归为「移动端只读/轻量」与「桌面端管理能力」两类，不当作缺陷。

## 1. 本轮修复

## 3. 排查中确认的非缺陷

- “解除配对”只清设备端配置，不会吊销桌面端设备记录；如需吊销在桌面「设置 → Bridge → 已配对设备」操作（两者语义不同）。
- 移动端打开历史会话会把权限模式切到该会话保存的值（例如“自动”），这是会话级设置，不是 UI 不同步。
- 移动端 Web 扫码需要 HTTPS/localhost；局域网 HTTP 会提示改用手输（安全上下文限制，非代码缺陷）。
