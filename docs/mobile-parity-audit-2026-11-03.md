# 移动端与桌面端一致性排查（2026-11-03）

> 范围：移动端 App（Expo Web 构建，390×844 / 兼容 320–768）与桌面端 Agent / 数据 / 设置能力对照。
> 方法：代码对照 + Playwright 驱动真实 Bridge（`127.0.0.1:8787`）逐项操作；脚本：`scripts/qa/mobile-parity.mjs`。
> 结论：修复 3 个用户反馈问题 + 3 个同源问题；剩余差异归为「移动端只读/轻量」与「桌面端管理能力」两类，不当作缺陷。

## 1. 本轮修复

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 点击「解除配对」没反应 | React Native Web 不实现带按钮的 `Alert.alert`，确认框从来不出现 | 统一 `confirmAction()`：Web 用 `window.confirm`，原生用 `Alert.alert`；解除配对、删除会话、删除记忆都走它 |
| 2 | 对话界面无法选择模型 / 思考程度 | 移动端只读展示 `boot.settings.agent`，没有入口；桌面端有模型胶囊 + 推理档位菜单 | 输入框上方新增「模型 · 档位」胶囊，弹层分「模型」「思考程度」两段；选择即 `PUT /settings`，与桌面共享 |
| 3 | 权限模式是标签点击 | 移动端用 4 个 chip 横排 | 改为单个下拉触发器（只读/询问/自动/全自动 + 说明），对话页与设置页共用 |
| 4 | 其他操作的错误提示在 Web 上是静默的 | 多处 `Alert.alert('xx失败')` 同样无实现 | 统一 `notify()`：Web 用 `window.alert`，原生用 `Alert.alert` |
| 5 | 会话不能改名 / 搜索 | 移动端只有列表、新建、删除 | 会话弹层加搜索框；每行加改名按钮（`PATCH /agent/sessions/:id`） |
| 6 | 记忆只能置顶 | 移动端只有搜索 + 置顶 | 新增新建/编辑/删除：kind、标题、内容，支持 fact/preference/schema/procedural |
| 7 | 连接下无法选择数据库 | 只选了连接，多库引擎（MySQL/PG 等）没有库级入口 | 对话头部新增数据库胶囊（多库时显示）；切换后 schema、表数据、Agent 会话与每轮消息都带 `database` |
| 8 | 底部只有 5 个入口，功能显薄 | 只有对话/数据/连接/记忆/设置 | 新增「工具」Tab：命令、常用任务、上下文统计，以及 SQL / 表结构 / 导入导出 / 备份 / 仪表板 / 搜索 / 字典 / 监控入口 |
| 9 | 没有 SQL 编辑器 | 只能让 Agent 代跑 | 新增 SQL 查询：多语句开关、结果表格、CSV/JSON 导出、存为仪表板卡片 |
| 10 | 数据只能看 | 只读行卡片 | 可写连接支持新增/编辑/删除行（按主键），无主键与只读连接自动禁用 |
| 11 | 不能改表结构 | 无入口 | 表结构页：列/索引查看、加列、建/删索引、重命名、清空、删除表 |
| 12 | 不能导入导出 | 无入口 | CSV 文件导入；表/查询结果导出 CSV/JSON（Web 下载、原生分享） |
| 13 | 没有备份入口 | 无入口 | 备份列表、立即备份、恢复（危险操作二次确认） |
| 14 | 没有仪表板 | 无入口 | 卡片列表、刷新、迷你趋势、删除；查询页可存卡片 |
| 15 | 没有搜索/字典/监控 | 无入口 | 数据库搜索（对象/数据）、数据字典 Markdown、服务器监控概览 |
| 16 | 不能发图片 | 只能文本 + @表 | 相册多选上传（最多 4 张），随轮次发给 Agent；可移除后重发 |
| 17 | 无法开关扩展 | 无入口 | 设置内列出 Skills 与 MCP Servers，支持启停 |
| 18 | 没有历史/审计 | 无入口 | 工具页新增查询历史（搜索/收藏/回填 SQL）与审计日志 |
| 19 | 没有报告/产物管理 | 无入口 | 工具页新增报告与产物：查看规格/运行结果、导出 XLSX/PPTX、删除 |
| 20 | 不能管理已配对设备 | 无入口 | 设置内列出已配对设备，标记当前设备，可吊销其它设备 |

## 3. 排查中确认的非缺陷

- “解除配对”只清设备端配置，不会吊销桌面端设备记录；如需吊销在桌面「设置 → Bridge → 已配对设备」操作（两者语义不同）。
- 移动端打开历史会话会把权限模式切到该会话保存的值（例如“自动”），这是会话级设置，不是 UI 不同步。
- 移动端 Web 扫码需要 HTTPS/localhost；局域网 HTTP 会提示改用手输（安全上下文限制，非代码缺陷）。
