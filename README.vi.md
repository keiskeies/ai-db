AiDB Studio lấy tác nhân làm cửa ngõ chính: kết nối, lược đồ, SQL, dữ liệu, bảng điều khiển, báo cáo và kiểm toán dùng chung một ngữ cảnh thực thi. Có 41 hệ quản trị cơ sở dữ liệu, 14 mô-đun năng suất và 53 công cụ cho tác nhân; mọi thao tác của tác nhân đều hiển thị, điều khiển được và kiểm toán được.

## Bộ cài

| Hệ điều hành | Kiến trúc | Tệp |
|---|---|---|
| Windows | x64 | `AiDB-Studio-<version>-x64-setup.exe` (NSIS) |
| Windows | arm64 | `AiDB-Studio-<version>-arm64-setup.exe` (NSIS) |
| macOS | Apple Silicon | `AiDB-Studio-<version>-arm64.dmg` |
| macOS | Intel | `AiDB-Studio-<version>-x64.dmg` |
| Linux | x64 | `AiDB-Studio-<version>-x86_64.AppImage` / `-amd64.deb` / `-x86_64.rpm` |
| Linux | arm64 | `AiDB-Studio-<version>-arm64.AppImage` / `-arm64.deb` / `-aarch64.rpm` |

Trên Windows on ARM, bộ cài x64 chạy qua giả lập hệ thống. Trên Linux, deb / rpm cài bằng trình quản lý gói, còn AppImage cần FUSE 2 (hoặc `--appimage-extract-and-run`).
